# XML 因子排序与权重重标定设计

日期：2026-08-24
状态：候选卡已实现；`locked: true`、`validationStatus: candidate`
范围：PartClassification 的 XML 因子分析与打分卡；不包含 KmAI、HTTP 或前端。

## 1. 背景与纠正

现有 `v1-folder-calibrated` 中的 `inner_cyl_balance` 权重 `4.0` 没有可追溯的计算过程。它只能说明该因子在当前学习集上是最强因子，不能说明 `4.0` 是由 XML 唯一推导出的最优值。

本设计重新分析现有 XML，并把以下两件事分开：

1. 因子排序：该因子单独区分两类的能力和稳定性。
2. 生产权重：去除高度相关的重复信息后，各独立证据组的相对贡献。

任何权重只能表示当前样本上的候选校准值，不能等同于总体最优参数或统计概率。

## 2. 样本与标签

学习集共20对 PRT/XML：

- 活门：10件，标签 `spool`
- 活门衬套：10件，标签 `sleeve`
- 标签来源：对应 PRT 文件夹；用户确认的压差活门仍为 `spool`

独立检查集：

- `source/测试样本/taotong.prt` + `taotong.XML`：用户确认是活门衬套
- `source/测试样本/衬套.prt` + `衬套.XML`：用户确认是活门衬套

独立检查集没有活门样本，因此只能检验衬套方向，不能估计两类完整的泛化准确率。测试样本不参与阈值、排序或权重计算。

## 3. 评估方法

### 3.1 因子方向与 AUC

对每个因子，分别计算衬套值大于活门值的成对排序比例；若反向更强，则反转方向。并列计半分。得到定向 AUC，范围 `[0, 1]`。

### 3.2 留组验证

样本存在相同 `JRT` 系列的配对件，因此不只做普通留一验证，还按 `JRT145-13`、`JRT148-01` 等系列做 family leave-one-group-out：每次拿掉一个系列，用剩余系列确定单因子方向和阈值，再预测被拿掉系列。

留组正确率用于防止同系列相似件泄漏造成过于乐观的结果。

### 3.3 Bootstrap 稳定性

按类别分别从10件学习样本有放回抽样，重复10,000次，计算定向 AUC 的2.5%分位数，作为保守下界。该区间只描述当前小样本的不确定性，不是总体置信区间的替代品。

### 3.4 可复算的排序强度

用于排序的候选指标定义为：

```text
evidence_strength
  = directional_auc
  * family_leave_group_out_accuracy
  * bootstrap_auc_lower_95
```

这是本项目的透明排序指标，不是机器学习训练目标。它同时惩罚区分力低、系列外不稳定或小样本不确定性大的因子。

## 4. 全部因子结果

单因子方向和阈值仅用于排序验证，不直接作为生产分类边界。生产画像使用每一类学习样本的经验范围，见第7节。

| 排名 | 因子 | 方向 | AUC | 按系列留组正确率 | Bootstrap AUC 下界 | 强度 |
|---:|---|---|---:|---:|---:|---:|
| 1 | `inner_cyl_balance` | 衬套高 | 1.00 | 19/20 = 0.95 | 1.00 | 0.95000 |
| 2 | `inner_cyl_ratio` | 衬套高 | 0.98 | 19/20 = 0.95 | 0.91 | 0.84721 |
| 3 | `outer_cyl_ratio` | 衬套低 | 0.89 | 18/20 = 0.90 | 0.70 | 0.56070 |
| 4 | `inner_rev_ratio` | 衬套高 | 0.88 | 17/20 = 0.85 | 0.70 | 0.52360 |
| 5 | `wall_to_outer` | 衬套低 | 0.93 | 14/20 = 0.70 | 0.80 | 0.52080 |
| 6 | `hollow_ratio` | 衬套高 | 0.78 | 17/20 = 0.85 | 0.54 | 0.35802 |
| 7 | `plane_ratio` | 衬套低 | 0.82 | 14/20 = 0.70 | 0.60 | 0.34440 |
| 8 | `slenderness` | 衬套低 | 0.66 | 9/20 = 0.45 | 0.51 | 0.15147 |

因此，严格按当前 XML 与 PRT 标签，因子排序为：

```text
inner_cyl_balance
> inner_cyl_ratio
> outer_cyl_ratio
> inner_rev_ratio
> wall_to_outer
> hollow_ratio
> plane_ratio
> slenderness
```

排序只说明单因子证据强弱，不说明可以把所有因子直接相加。

## 5. 相关性与重复信息

当前样本中的 Pearson 相关系数：

| 因子对 | 相关系数 |
|---|---:|
| `inner_cyl_balance` / `inner_cyl_ratio` | 0.978545 |
| `inner_cyl_balance` / `outer_cyl_ratio` | -0.902300 |
| `inner_cyl_ratio` / `outer_cyl_ratio` | -0.800751 |
| `inner_cyl_balance` / `wall_to_outer` | -0.817847 |
| `inner_cyl_ratio` / `plane_ratio` | -0.829687 |

其中前三项实际上描述同一组内外圆柱面构成信息。若保留三项并分别给高权重，会把同一结构事实重复计算三次。因此生产权重采用“证据组”而不是把单因子强度直接归一化。

## 6. 候选证据组与权重

### 6.1 证据组

| 证据组 | 因子 | 处理 |
|---|---|---|
| 圆柱面构成组 | `inner_cyl_balance`、`inner_cyl_ratio`、`outer_cyl_ratio` | 高相关，只计一组；推荐 `inner_cyl_balance` 作代表 |
| 内部回转面组 | `inner_rev_ratio` | 独立辅助组 |
| 薄壁组 | `wall_to_outer` | 独立辅助组，但系列外稳定性较弱 |
| 平面组 | `plane_ratio` | 弱辅助组 |
| 形状补充组 | `hollow_ratio`、`slenderness` | 暂不进入生产分数 |

`hollow_ratio` 虽然单因子强度略高于 `plane_ratio`，但“最小内径”容易受倒圆和侧孔影响，且已知压差活门是边界件；它保留在诊断输出，不进入候选生产卡。`slenderness` 的系列外正确率只有9/20，不进入生产分数。

### 6.2 组权重计算

圆柱面构成组只取组内最大强度，避免相关因子重复加分；其他组取其唯一因子强度：

```text
cylinder_group = max(0.95000, 0.84721, 0.56070) = 0.95000
inner_rev_group = 0.52360
wall_group      = 0.52080
plane_group     = 0.34440
```

归一化总和为 `2.33880`，候选组权重为：

| 证据组 | 原始强度 | 归一化权重 |
|---|---:|---:|
| 圆柱面构成组 | 0.95000 | 0.406191 |
| 内部回转面组 | 0.52360 | 0.223875 |
| 薄壁组 | 0.52080 | 0.222678 |
| 平面组 | 0.34440 | 0.147255 |

推荐展示时四舍五入为：

```text
圆柱面构成组 0.41
内部回转面组 0.22
薄壁组       0.22
平面组       0.15
```

生产卡中四个六位小数权重相加为 `0.999999`；评分会按本轮实际有效组权重和归一化。它们是候选校准值，不是训练结果、概率或总体最优值。

### 6.3 因子级生产权重

为避免重复计分，推荐生产分数中只使用圆柱面构成组的代表因子：

| 因子 | 候选生产权重 | 状态 |
|---|---:|---|
| `inner_cyl_balance` | 0.406191 | 圆柱面构成组代表 |
| `inner_cyl_ratio` | 0 | 诊断保留，组内重复 |
| `outer_cyl_ratio` | 0 | 诊断保留，组内重复 |
| `inner_rev_ratio` | 0.223875 | 独立辅助 |
| `wall_to_outer` | 0.222678 | 独立辅助 |
| `plane_ratio` | 0.147255 | 弱辅助 |
| `hollow_ratio` | 0 | 暂不进生产分数 |
| `slenderness` | 0 | 暂不进生产分数 |

候选总分为：

```text
score =
  0.406191 * cylinder_match
+ 0.223875 * inner_rev_match
+ 0.222678 * wall_match
+ 0.147255 * plane_match
```

对每一个类别，`*_match` 的定义是：因子值落在该类别学习样本的经验范围内为1，否则为0。两个类别的经验范围允许重叠，因此一个辅助因子可以同时支持两类；这比强制用单一中点把重叠样本二选一更忠实于当前数据。

缺失组应在剩余有效组之间重新归一化；不能把缺失当作0分。值有效但落在两类范围之外时，该组对两类均为0。`inner_cyl_ratio` 和 `outer_cyl_ratio` 仍可用于理由和诊断，但不再独立加分。

## 7. 阈值与边界件

### 7.1 分析中点

按20件学习集得到的单因子分析中点如下。它们只用于第4节的单因子排序和验证，不直接写入候选生产卡：

| 因子 | 衬套方向 | 分析中点 |
|---|---|---:|
| `inner_cyl_balance` | 高 | 0.425769326 |
| `inner_cyl_ratio` | 高 | 0.287500000 |
| `outer_cyl_ratio` | 低 | 0.435500000 |
| `inner_rev_ratio` | 高 | 0.341299700 |
| `wall_to_outer` | 低 | 0.265564706 |
| `plane_ratio` | 低 | 0.260500000 |
| `hollow_ratio` | 高 | 0.358750000 |
| `slenderness` | 低 | 2.905000000 |

### 7.2 候选生产画像范围

候选生产画像使用20件学习样本中各类的实际最小值和最大值，不使用无记录依据的人工外扩。生产 JSON 保存全精度端点；下表约保留9位小数，仅为展示，不能替换严格判定使用的实际端点：

| 因子 | 活门衬套经验范围 | 活门经验范围 |
|---|---:|---:|
| `inner_cyl_balance` | [0.433380084, 0.502170767] | [0.071212121, 0.418158568] |
| `inner_rev_ratio` | [0.371801970, 0.603647895] | [0.060164917, 0.438915538] |
| `wall_to_outer` | [0.139818182, 0.358200000] | [0.216444444, 0.564250000] |
| `plane_ratio` | [0.074000000, 0.258000000] | [0.195000000, 0.373000000] |

`inner_cyl_balance` 的两类范围不重叠。三个辅助因子的两类范围存在重叠，重叠值应同时给两类加分，而不是被强制分到某一类。

### 7.3 判定闸门

候选判定按以下顺序执行：

1. `inner_cyl_balance` 必须有效，并且只能命中一个类别的经验范围；未命中任何类或同时命中两类时返回 `unknown`。
2. 除主因子外，至少有一个有效辅助证据组命中主因子指向的类别；否则返回 `unknown`。
3. 按第6节权重计算两类分数；最高分类别必须与主因子方向一致，否则返回 `unknown`。
4. 两类得分相等时返回 `unknown`；不再沿用缺乏重标定依据的固定 `0.50` 最高分和 `0.10` 分差闸门。
5. `possibility` 仍由两类 `score` 归一化得到，但它是相对匹配度，不是统计概率。

现有压差活门 `JRT145-17-01` 是用户确认的活门。其 `inner_cyl_balance` 命中活门范围，而三个辅助因子同时落入两类重叠范围，因此活门得分为1.0、衬套得分约0.593809，最终保持活门。该边界件必须作为回归测试，确保辅助证据不能推翻主方向。

## 8. 验证结果与限制

在“经验范围 + 主方向闸门 + 候选组权重”的回放中：

- 20件完整学习集回放：20/20正确、0未定、0误判。该结果只能证明配置与标定集一致，不能当作泛化准确率。
- 两件独立衬套：`taotong` 和 `衬套` 均正确判为衬套。
- 按 `JRT` 系列留组验证：16/20正确、4/20未定、0误判。四件未定分别是 `JRT145-17-01压差活门`、`JRT148-06-01区执行活门衬套`、`JRT148-12-02区联锁活门`、`JRT148-12-01区联锁活门衬套`；它们的主因子超出其余系列形成的两类经验范围，因此保守拒判。
- 独立集没有活门样本，不能声称两类泛化准确率。
- 样本只有20件，且存在同系列配对件；即使使用系列留组验证，结果仍不能替代更大规模外部验证。

因此本设计的状态只能是：

```text
v2-evidence-group-calibrated-candidate
```

候选卡可以固定参数并用于实际测试，但必须区分两个状态：

- `locked: true`：权重、经验范围和闸门已经固定，运行时可以输出分类结果；不表示统计验证已经完成。
- `validationStatus: candidate`：只有两件独立衬套样本，尚缺独立活门样本，不能宣称为已验证生产卡。

至少补充已确认 PRT 真值的独立活门样本并通过验收后，才可将 `validationStatus` 升为 `validated`。

## 9. 实施结果

候选设计已经写入默认生产卡 `v2-evidence-group-calibrated-candidate`：

1. 打分卡结构已加入证据组；圆柱面组只以 `inner_cyl_balance` 为代表，组内诊断因子不重复计分；评分按实际有效组权重和归一化。
2. `scorecard.json` 为 `locked: true`、`validationStatus: candidate`，并已移除旧卡中没有可追溯计算过程的 `inner_cyl_balance: 4.0` 单因子重复权重。
3. 候选闸门已实现：主因子唯一命中、至少一个独立辅助组支持、辅助总分不能推翻主方向、并列拒判；不再使用固定 `0.50` / `0.10` 闸门。
4. 生产 JSON 保存学习 XML 的全精度经验 min/max。第7.2节表格约保留9位小数，只供阅读展示；不得反向将展示值写回生产端点，以免严格区间边界排除真实极值。
5. 回归验证覆盖组内不重复放大、缺失组归一化、经验范围重叠、主方向冲突拒判、边界压差活门、两件独立衬套和按系列留组0误判。

这不改变第8节的验证结论：候选卡可运行，但尚缺有确认 PRT 真值的独立活门样本，`validationStatus` 必须继续保持 `candidate`。项目输入仍仅为 XML；PRT 只用于学习标定，不引入黑盒训练、HTTP 或 KmAI。
